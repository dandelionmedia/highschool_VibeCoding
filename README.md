# VIBE CODING LAB · 고등학생 바이브코딩 프롬프트 가이드

고등학생용 구글 제미나이 캔버스 바이브코딩 실습 프롬프트 웹페이지입니다.
총 309개 실습 프롬프트(패션디자인 전공 특화 60개 포함), 추가 미션 316개, 문제 해결 프롬프트 8개가 들어 있습니다.

## 폴더 구성

```
index.html            ← 첫 화면
css/style.css         ← 디자인
js/data.js            ← 프롬프트 내용 (내용 수정은 이 파일만!)
js/main.js            ← 복사 버튼, XP·퀘스트, 필터·검색, 상세 창, 맨위 버튼 동작
fonts/                ← 픽셀 글꼴 (Galmuri, SIL OFL 1.1)
```

## GitHub Pages로 올리기

1. GitHub에서 새 저장소(Repository)를 만듭니다. (예: `highvibe`)
2. **Add file → Upload files**에서 이 폴더 안의 파일과 폴더를 **구조 그대로** 모두 올립니다.
   (index.html이 저장소 맨 위에 있어야 합니다.)
3. **Settings → Pages → Branch**를 `main` / `(root)`로 정하고 Save를 누릅니다.
4. 1~2분 뒤 `https://내아이디.github.io/저장소이름/` 주소로 열립니다.

## 화면 구성

- STAGE 00 실습 준비: 제미나이 캔버스 7단계, 수업 전 약속, 난이도 안내
- STAGE 01 프롬프트 설계도: 7개 블록 구조
- STAGE 02 미션 309: 분야 그룹(패션 전공 / 학교생활 / 취미 / 게임 / 진로 탐색 20) → 세부 분야, 검색(번호·키워드), 난이도·종류 필터, 랜덤 미션 뽑기
  - 카드를 누르면 프롬프트 전체 + 추가 미션(각각 복사 버튼) + 이전/다음 미션
  - 카드의 ⚡ 바로 복사로 상세 창 없이 바로 복사
- STAGE 03 버그 픽스: 막힐 때 쓰는 문제 해결 프롬프트 8개
- STAGE 04 나만의 프롬프트: 빈칸을 채우면 7블록 구조 프롬프트가 자동 완성

## 프롬프트 고치기

`js/data.js`를 열어 큰따옴표(") 안의 글자만 바꾸면 됩니다. 줄바꿈은 `\n`으로 씁니다.

- `title` 주제 이름 / `what` 카드에 보이는 한 줄 설명 / `prompt` 복사되는 프롬프트 / `missions` 추가 미션 목록
- `lv`는 1 쉬움, 2 보통, 3 도전 / `type`은 "웹앱" 또는 "게임"

## 참고

- 복사 버튼은 https 주소(GitHub Pages)에서 가장 잘 작동합니다. 학교 PC에서 막히면 글자가 자동으로 선택되므로 Ctrl+C로 복사하면 됩니다.
- 효과음은 소리 파일 없이 브라우저에서 직접 만듭니다. 오른쪽 위 SOUND 버튼으로 끄고 켤 수 있고, 음량은 js/main.js의 `master.gain.value` 값(기본 0.2)으로 조절합니다.
- XP와 퀘스트 기록은 새로고침하면 처음부터 다시 시작합니다. 다음 반 수업에 바로 쓸 수 있습니다.
